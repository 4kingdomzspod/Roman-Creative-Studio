## Operating System (`docs/`)

The `docs/` directory contains the complete Roman Creative Studio Operating System — every process, framework, and standard that runs the business.

| Folder | Contents |
|--------|----------|
| `docs/website-system-engine/` | Website architecture, SEO, performance, conversion, mobile |
| `docs/client-experience-system/` | Client journey, onboarding, QA, communication, retention |
| `docs/sales-system-engine/` | Lead gen, discovery calls, proposals, objection handling, closing |
| `docs/marketing-engine-system/` | Content strategy, SEO, email, social, blog, case studies |
| `docs/business-systems/` | CRM, client portal, PM framework, automation, security |
| `docs/financial/` | Revenue model, pricing, MRR, cash flow, budgeting, KPIs |
| `docs/business-intelligence/` | Executive dashboard, KPI definitions, forecasting, analytics |
| `docs/team/` | Org chart, roles, hiring, onboarding, culture, handbooks |
| `docs/growth/` | Growth audit and strategy |
| `docs/innovation/` | Product roadmap, AI tools, courses, community, SaaS ideas |
| `docs/enterprise/` | Governance, OKRs, risk, security, compliance, legacy roadmap |

The master index is at **`docs/enterprise/CompanyPlaybook.md`**.
