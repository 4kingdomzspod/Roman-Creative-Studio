## Lead Capture Strategy

Currently these pages appear to be freely accessible without email capture. Options:
1. **Open access** (current) — best for SEO, lower lead capture
2. **Email gate** — PDF download version requires email; HTML version stays open
3. **Exit intent** — overlay popup when user moves to leave page

Recommendation: Keep HTML versions open for SEO; offer PDF download versions with email capture to build the email list.
