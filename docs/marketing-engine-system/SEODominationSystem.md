# SEO Domination System
## Roman Creative Studio — Phase 7: Marketing Engine System

---

## Purpose of This Document

This document defines the complete SEO architecture for Roman Creative Studio. It governs keyword strategy, page structure, silo architecture, internal linking, and local SEO — everything required to rank high-intent commercial and informational keywords across all target industries.

SEO is the highest-value long-term marketing investment RCS makes. Every page must either rank, convert, or both.

---

## SEO Philosophy

> **SEO is not about tricking Google. It is about becoming the most relevant, most trusted answer to the questions your ideal clients are already asking.**

RCS SEO strategy is built on three principles:

1. **Topical Authority** — Go deep in fewer industries rather than shallow across many
2. **Intent Alignment** — Every page targets a specific search intent (commercial, informational, local)
3. **Conversion Architecture** — Rankings mean nothing without conversion. Every ranked page drives toward a Discovery Call.

## Keyword Clustering Strategy

**Rule:** One page per topic cluster. Never split a cluster across multiple pages (keyword cannibalization).

### How to Build a Keyword Cluster

A keyword cluster is a group of semantically related keywords that all map to a single page's topic.

**Example: Dental Industry Page Cluster**
```
Primary keyword:    dental website design
Secondary keywords: website for dental practice
                    dental practice website
                    web design for dentists
                    dentist website design agency
                    dental clinic website
LSI keywords:       patient booking online
                    dental SEO
                    dental practice online presence
                    HIPAA-compliant dental website
```

All of these keywords are served by ONE page: `/industries/dental-website-design/`

## Long-Tail Keyword Strategy

Long-tail keywords (3–6 words, lower volume, higher intent) convert at significantly higher rates than short-tail keywords. RCS targets long-tail keywords primarily through:

1. **FAQ sections** on every service and industry page
2. **Blog articles** targeting question-format searches
3. **H2/H3 subheadings** within long-form pages

**Example long-tail targets per industry:**

| Industry | Long-Tail Keyword | Format |
|---|---|---|

| Restaurant | `how to take online reservations on restaurant website` | FAQ on restaurant page |
| Startup | `how much does a startup website cost` | Blog article |

## Local SEO Strategy

RCS serves clients nationally but maintains a local SEO presence to capture high-intent local searches.

### Google Business Profile
- Fully completed profile: name, category, description, hours, website URL (`romancreativestudio.co`)
- Regular Google Posts (weekly): new projects, articles, offers
- Photo uploads: completed projects, team, office (if applicable)
- Review request system: after every successful project launch
- Response to all reviews within 24 hours

### Local Citation Consistency
- NAP (Name, Address, Phone) consistent across: Google, Yelp, Facebook, Clutch.co, DesignRush, Agency Spotter
- All citations link to `https://romancreativestudio.co`

### Location-Based Pages (If Applicable)
If RCS targets specific cities, create:
- `/web-design-[city]/` pages with localized content
- Example: `/web-design-houston/`, `/web-design-dallas/`

### Schema Markup — LocalBusiness
```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Roman Creative Studio",
  "url": "https://romancreativestudio.co",
  "email": "Alexander@romancreativestudio.co",
  "description": "Premium web design agency specializing in conversion-focused websites for service businesses."
}
```

## On-Page SEO Standards

### Title Tag Formula
```
[Primary Keyword] | Roman Creative Studio
```
- Maximum 60 characters
- Primary keyword as close to the start as possible
- Never duplicate title tags across pages

### Meta Description Formula
```
[Benefit statement including primary keyword]. [Secondary point]. [CTA phrase].
```
- 150–160 characters
- Includes primary keyword naturally
- Ends with an action phrase

### Heading Hierarchy
- **H1:** One per page. Contains primary keyword. Outcome-oriented.
- **H2:** Section dividers. Include secondary and LSI keywords.
- **H3:** Sub-sections under H2. Include long-tail and question keywords.
- **H4+:** Use sparingly for structured content (checklists, tables).

### URL Structure
```
https://romancreativestudio.co/[silo]/[page-slug]/
```
- All lowercase
- Hyphens between words (no underscores)
- No dates in URLs (creates maintenance burden)
- No stop words (`a`, `the`, `and`) unless essential for readability

## Technical SEO Requirements

| Item | Requirement |
|---|---|
| HTTPS | Enforced on all pages |
| Canonical tags | Set on every page (self-referencing) |
| robots.txt | Properly configured; no strategic pages blocked |
| sitemap.xml | Auto-generated; submitted to Google Search Console |
| Core Web Vitals | LCP < 2.5s / CLS < 0.1 / INP < 200ms |
| Mobile-first | All pages fully functional and fast on mobile |
| No duplicate content | Each page has unique title, description, and body content |
| 301 redirects | Any removed or renamed pages get 301 redirects |
| Image alt text | Every image has descriptive, keyword-relevant alt text |
| Internal links | Minimum 3 internal links per page |
