## Purpose

Define each department of Roman Creative Studio — its mission, responsibilities, team composition at each growth stage, success metrics, and cross-department relationships.

**Business Value:** Prevents scope confusion between departments. Defines ownership clearly so projects never fall through cracks. Gives future department heads a clear mandate.

**Owner:** CEO / COO  
**Version:** 1.0  
**Related Documents:** OrganizationChart.md, RoleDescriptions.md, HiringRoadmap.md

---

## Department 1: Creative

**Mission:** Deliver visually exceptional, brand-aligned creative work that makes clients' businesses look like leaders in their industry.

**Core Responsibilities:**
- Web design (UI, UX, wireframing, mockups)
- Brand identity (logos, color systems, typography, guidelines)
- Visual assets (icons, illustrations, photography direction)
- Design system development and maintenance
- Creative quality assurance on all client deliverables
- Accessibility compliance in all design work

**Roles (by stage):**

| Stage | Roles |
|-------|-------|
| Stage 1 | CEO (solo) |
| Stage 2 | 1 Part-time Designer |
| Stage 3 | Creative Director + 1 UI Designer |
| Stage 4 | Creative Director + UI + UX + Brand Designer |
| Stage 5+ | CCO + Creative Director + multiple specialists |

**KPIs:**
- Client design approval on first round: >60%
- Average revision rounds per project: <2.5
- Design-to-development handoff errors: <3 per project
- Client satisfaction score (design): >4.5/5
- WCAG 2.1 AA pass rate: 100% on all deliverables

**Tools:** Figma, Adobe Creative Cloud, Spline (3D), Framer (motion), Storybook

**Cross-department dependencies:**
- → Development: Design system, component specs, Figma tokens
- → Marketing: Brand assets, social templates, content graphics
- → Sales: Portfolio assets, proposal design
- ← Client Success: Client feedback, revision requests

## Department 2: Development (Engineering)

**Mission:** Build fast, accessible, secure, and maintainable digital products that perform at the highest technical standard.

**Core Responsibilities:**
- Frontend development (HTML, CSS, JavaScript, React/Next.js)
- Backend development (Node.js, Supabase, APIs)
- Performance optimization (Core Web Vitals, PageSpeed)
- Accessibility implementation (WCAG 2.1 AA)
- Code review and quality control
- Technical architecture decisions
- GitHub workflow and version control standards
- Third-party integrations (Stripe, MailerLite, Zapier, etc.)
- Client portal and admin dashboard development

**Roles (by stage):**

| Stage | Roles |
|-------|-------|
| Stage 1 | CEO (solo) |
| Stage 2 | 1 Contractor (Frontend) |
| Stage 3 | 1 FT Frontend Developer |
| Stage 4 | Frontend Dev + Backend Dev + QA Specialist |
| Stage 5+ | Engineering Director + FE + BE + QA + DevOps |

**KPIs:**
- Google PageSpeed score: >90 on all launches
- Accessibility score: 100% WCAG AA compliance
- Bug count post-launch (30 days): <3 per project
- Code review coverage: 100% of PRs reviewed
- On-time technical delivery: >90%

**Tools:** VS Code, GitHub, Vercel, Netlify, Supabase, Stripe, Node.js, Next.js, TypeScript

**Cross-department dependencies:**
- ← Creative: Design specs, Figma files, component requirements
- → QA: Staging environment for testing
- → Operations: Deployment documentation
- ← Client Success: Post-launch bug reports
