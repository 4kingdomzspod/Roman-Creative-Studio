## Architecture Decision Point

At 15–20 pages, evaluate whether to migrate from static HTML to a static site generator (Eleventy, Astro) to:
- Eliminate duplicated nav/footer HTML
- Enable templated page generation for industry pages
- Improve maintainability at scale

Decision criteria: If adding a new page takes more than 30 minutes due to nav/footer copying and updating, the SSG migration ROI is justified.
