# Episode Workflow
Repeatable steps per episode. Status values match `episodes/epNN.md` (SYSTEM.md §9). Full workflow diagram: README.md.

## Before editing
- [ ] Create/open `episodes/epNN.md`, status PLAN
- [ ] Import footage into `01_RAW/NEW/` (ASSET-SYSTEM.md)
- [ ] Review footage, status FILM → INGEST
- [ ] Pull selects into `02_SELECTS/`, status SELECT
- [ ] Confirm the story: hook, conflict, action, result (episode file's Story beats)

## Editing
- [ ] Open the episode master template (CapCut daily / DaVinci weekly — SYSTEM.md §6/§7), status EDIT
- [ ] Duplicate timeline/draft, rename `RCS90_EPNN_MASTER`
- [ ] Drop in `RCS90_INTRO_*_v01` unmodified (DAVINCI-BUILD.md / CAPCUT-BUILD.md)
- [ ] Edit episode content into slots 4–10 (SYSTEM.md §6)
- [ ] Update progress tracker: DAY XX/90, $X/$10,000 (from STATE.md)
- [ ] Music + SFX (SYSTEM.md §3)
- [ ] Color correct (SYSTEM.md §4)

## QC + Export
- [ ] Run QC checklist, status QC — SYSTEM.md §10
- [ ] Export per EXPORT-STANDARD.md, status EXPORT
- [ ] Save final to `08_EXPORTS/` as `RCS90_EPNN_FINAL`

## Publish + close out
- [ ] Publish TikTok + Reels, status PUBLISH
- [ ] Fill Review notes in `episodes/epNN.md`, status REVIEW
- [ ] Update STATE.md (Day, Revenue, Latest/Next episode, Known Improvements), status DONE
