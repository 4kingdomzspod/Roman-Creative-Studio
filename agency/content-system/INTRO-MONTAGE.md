## Editing Language (applies to both editors)
Primary: hard cut, match cut, movement-based cut. Secondary (use sparingly, only when it improves the cut): whip, speed ramp, punch-in. Avoid: zoom-transition presets, spins, glitches, light leaks, unearned wipes. Same restraint rule as SYSTEM.md §3.
