## Overview

The RCS Prompt Library is our institutional knowledge base for AI-assisted work. These prompts represent tested, refined approaches to common agency tasks. They encode our methodology, our standards, and our voice.

**Purpose:** Eliminate prompt reinvention. Every team member should have access to battle-tested prompts that produce consistent, on-brand output.

**Library Ownership:** CIO maintains the master library. All team members can submit prompts. Monthly review and curation cycle.

**Format Standard:** All prompts use the RCS prompt format: Role → Task → Context → Output Format → Constraints.

---

## Prompt Format Template

```
[ROLE]
You are [specific role with expertise level and relevant credentials].

[TASK]
Your task is to [specific action verb + deliverable].

[CONTEXT]
- Business: [description]
- Industry: [industry]
- Goal: [primary goal]
- Audience: [target audience]
- Additional context: [any relevant details]

[OUTPUT FORMAT]
Provide your response as:
- [Section 1]
- [Section 2]
- [Section 3]

[CONSTRAINTS]
- [Constraint 1]
- [Constraint 2]
- Tone: [tone description]
- Length: [approximate length]
```

## Category 1: Branding Prompts

### PROMPT-BRAND-01: Brand Positioning Statement
```
[ROLE]
You are a senior brand strategist with 15 years of experience positioning service businesses for premium markets.

[TASK]
Create a brand positioning statement for the following business.

[CONTEXT]
- Business: {business_name} — {one_line_description}
- Industry: {industry}
- Target audience: {audience_description}
- Primary differentiator: {what_makes_them_different}
- Competitors: {2-3 competitors}
- Current perception: {how_people_see_them_now}
- Desired perception: {how_they_want_to_be_seen}

[OUTPUT FORMAT]
Provide:
1. Positioning Statement (1 sentence, classic format: For [audience] who [need], [brand] is the [category] that [differentiator] because [proof])
2. 3 Alternative Positioning Statements (different angles)
3. Key Messaging Pillars (3 supporting messages that reinforce positioning)
4. What to AVOID saying (3 phrases that undermine the positioning)

[CONSTRAINTS]
- Avoid jargon and buzzwords
- Positioning must be ownable (not generic)
- Must be verifiable (backed by something real)
- Tone: Confident, clear, professional
```

### PROMPT-BRAND-02: Brand Voice Guide
```
[ROLE]
You are a brand copywriter and voice strategist specializing in small-to-mid-size service businesses.

[TASK]
Develop a brand voice guide for {business_name}.

[CONTEXT]
- Brand positioning: {positioning_statement}
- Target audience: {audience_description}
- Industry: {industry}
- 3 words that describe the brand personality: {word_1}, {word_2}, {word_3}
- Example of communication they admire: {example_brand_or_communication}

[OUTPUT FORMAT]
1. Voice Overview (2–3 sentences describing the voice)
2. Four Voice Dimensions (each with: dimension name, description, DO example, DON'T example)
3. Vocabulary Guide (10 words/phrases TO USE, 10 words/phrases to AVOID)
4. Tone Variations by Context (how voice adapts for: website, social media, email, proposals, error messages)
5. Sample Sentences (write the same message 3 ways: too formal, too casual, just right)

[CONSTRAINTS]
- Must be practical and easy for non-writers to follow
- Include real before/after examples
- Avoid abstract descriptions — use concrete examples
- Length: 600–900 words
```

```
[ROLE]
You are an award-winning copywriter specializing in taglines for service businesses.

[TASK]
Generate 15 tagline options for {business_name}.

[CONTEXT]
- Business: {description}
- What they do: {primary_service}

[OUTPUT FORMAT]

- Group 2: Process/approach-focused (how they do it)
- Group 3: Emotional/aspirational (feeling and identity)
- Group 4: Bold/provocative (attention-grabbing)

- Avoid rhymes unless they feel natural
- All must be grammatically correct
```

  [etc.]

[OUTPUT FORMAT]

## Library Management

### Submission Process
1. Team member drafts prompt using the standard format
2. Test prompt minimum 5 times with varied inputs
3. Submit via Slack #prompt-library with: category, use case, test results, output sample
4. CIO reviews at monthly library session
5. Approved prompts added to master library
6. Contributor credited in library notes

### Monthly Review Cadence
- First Monday of each month: 30-minute library review
- Review: new submissions, underperforming prompts, major AI model updates
- Deprecate prompts that no longer produce quality output
- Update prompts when new Claude model capabilities become available

### Version Control
- Prompts versioned as v1.0, v1.1, v2.0
- Breaking changes (different output format) = major version
- Improvement tweaks = minor version
- Old versions archived, not deleted

### Access
- Full library: All RCS team members via Notion
- Client-facing version: Subset of prompts shared with Care Plan clients
- Public version (Year 2): Prompt Library digital product — curated 50-prompt guide
