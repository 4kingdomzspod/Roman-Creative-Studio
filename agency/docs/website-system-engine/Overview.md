# Phase 4 — Website System Engine
## Roman Creative Studio (Conversion, UX & SEO Architecture)

---

### System Purpose

Phase 4 transforms the Roman Creative Studio website from a digital brochure into a high-converting, SEO-optimized, scalable agency sales engine.

It does not rebuild the brand. It does not redesign the visual identity. It engineers the strategy, structure, and performance layer that makes every page purposeful.

### Governing Principles

1. **Every page serves ONE primary intent.** No mixed-purpose pages.
2. **Every page has ONE dominant CTA.** No competing conversion goals.
3. **Every decision is tested against five questions:**
   - Does this increase conversion?
   - Does this improve clarity?
   - Does this strengthen SEO?
   - Does this reduce user friction?
   - Does this align with the design system?
4. **Trust is layered throughout the site** — not isolated to one section.
5. **The design system (Phase 2B + Phase 3) is law.** No new tokens, colors, or components outside that system.

---

### System Stack

```
Phase 2A — Brand Bible        → Voice, values, positioning
Phase 2B — Visual Identity    → Tokens, typography, color
Phase 2C — Governance         → Rules and enforcement
Phase 3  — Design System      → Components and UI patterns
Phase 4  — Website System     → Conversion, SEO, UX architecture
```

Phase 4 sits at the top of the stack. It uses everything below it.

---

### What Phase 4 Is Not

- Not a redesign
- Not a rebrand
- Not a CMS migration
- Not a from-scratch rebuild
- Not a creative exercise

Phase 4 is **engineering**. Strategy meets execution.
