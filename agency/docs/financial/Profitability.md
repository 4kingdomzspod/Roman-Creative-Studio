## Purpose

Document the profitability framework for every Roman Creative Studio service. Estimate time investment, operational cost, labor cost, expected margin, risk, upsell potential, automation opportunity, and long-term value. Establish optimization targets for each service.

---

## Business Value

Not all revenue is equal. A $3,500 project that takes 60 hours is less profitable than a $1,500 landing page that takes 8 hours. This document ensures RCS pursues the highest-margin work and continuously improves efficiency across every service.

---

## Profitability Framework

### Definitions

```
Gross Revenue:     Total amount billed to client
Direct Costs:      Software costs per project + contractor costs per project
Gross Profit:      Gross Revenue - Direct Costs
Gross Margin:      Gross Profit / Gross Revenue × 100

Effective Hourly Rate:  Gross Revenue / Total Hours Invested
Target EHR:             $150+ (minimum viable), $200+ (healthy), $300+ (excellent)

Net Margin:        After allocating a portion of fixed overhead (software subscriptions,
                   business expenses) to each project
```

### Overhead Allocation Model
```
Monthly fixed overhead estimate (Stage 1):
  Software subscriptions: $300–$500/month
  Business expenses: $100–$200/month
  Total: $400–$700/month

Overhead allocation per project:
  If completing 2 projects/month: $200–$350 overhead per project
  If completing 1 project/month: $400–$700 overhead per project
```

### PROF-01 — BUILD Website ($3,500)

| Factor | Estimate |
|--------|----------|
| Gross Revenue | $3,500 |
| Total Hours | 35–45 hours |
| Effective Hourly Rate | $78–$100/hour |
| Direct Software Cost | $0–$50 (stock assets, tools) |
| Contractor Cost | $0 (solo delivery) |
| Gross Profit | $3,450–$3,500 |
| Gross Margin | ~98% (before overhead) |
| Net Margin (after overhead) | 85–90% |

**Risk Level:** Low — well-defined scope, clear deliverables

**Profit Killers:**
- Scope creep (each extra hour = $78–$100 opportunity cost)
- Client content delays extending project timeline
- Excessive revision rounds beyond policy

**Optimization Opportunities:**
- Component library reduces hours from 40 to 25 (+60% effective rate improvement)
- AI-generated copy drafts save 4–6 hours per project
- Standard questionnaire eliminates 2–3 discovery revision cycles

**Upsell Potential:**
- Care Plan: +$197/mo ($2,364/year additional LTV)
- Performance add-on: +$500–$800
- Accessibility add-on: +$500–$750

**Target EHR:** $100–$150 (achievable with systematization)

| Direct Software Cost | $50–$150 |

| Gross Margin | ~98% (before overhead) |

**Upsell Potential:**
- SEO Retainer: +$497/mo ($5,964/year)
- AI Automation setup: +$2,000–$3,000

**Target EHR:** $100–$130

### PROF-03 — SCALE Website ($12,000–$25,000)

| Factor | Estimate (at $15,000) |
|--------|---------------------|
| Gross Revenue | $15,000 |
| Total Hours (Alexander) | 60–80 hours |
| Contractor Cost | $2,000–$4,000 (design + dev) |
| Gross Profit | $11,000–$13,000 |
| Gross Margin | 73–87% |
| Net Margin (after overhead) | 65–80% |

**Risk Level:** High — complex projects, multiple stakeholders, technical risk

**Profit Killers:**
- Underscoping in proposal (most common SCALE risk)
- Contractor quality issues requiring rework
- Client-side delays on a long timeline

**Optimization Opportunities:**
- Detailed technical discovery before proposal prevents underscoping
- Fixed milestone-based contractor payments (not hourly) protect margin
- SCALE clients are highest-value Growth Partner candidates

**Upsell Potential:**
- Growth Partner: +$997/mo ($11,964/year)
- AI Automation: +$3,000–$5,000 setup + $300/mo maintenance

## Profitability Optimization Roadmap

### Phase 1 — Now (Month 1–3)
```
Priority: Establish baseline profitability
  1. Track hours per project from Day 1 (Toggl or manual log)
  2. Record all software costs as expenses
  3. Calculate actual EHR after each project
  4. Compare to targets in this document
  5. Build component library (BUILD delivery time target: 25 hours)
```

### Phase 2 — Month 3–6
```
Priority: Systematize high-volume services
  1. AI automation for Care Plan reporting (target: 1 hour/client/month)
  2. Landing page template library (target: 6-hour delivery)
  3. Proposal template that cuts proposal writing from 3 hours to 45 minutes
  4. Onboarding questionnaire eliminating discovery back-and-forth
```

### Phase 3 — Month 6–12
```
Priority: Margin expansion through portfolio shift
  1. Move default offering from BUILD to GROW (higher APV, similar margin)
  2. Raise BUILD price from $3,500 to $4,000 (annual review)
  3. Introduce rush fee as standard policy
  4. Pursue Accessibility Audits as high-EHR entry-point service
```
