## Annual Software Audit Protocol

**When:** Every January (alongside budget review)

**Process:**
1. Export full list of all active subscriptions (from credit card statements + 1Password)
2. For each subscription: Was it used 20+ days/month in the past 6 months? If no, cancel.
3. Are there free alternatives that meet our needs now? If yes, evaluate switching.
4. Are we using the full plan features? If using only 20% of a Pro plan, downgrade.
5. Are any annual subscriptions up for renewal? Negotiate before auto-renewal.
6. Total new year software budget confirmed and filed in Budgeting.md.

**Cancellation SOP:**
1. Confirm data export before cancellation
2. Cancel before next billing date
3. Remove from software cost tracker
4. Update any documentation referencing the tool
5. Communicate to team (if shared tool)

## Software Evaluation Criteria

Before adding any new subscription:

| Criterion | Question |
|-----------|----------|
| Problem | What specific problem does this solve? |
| Alternatives | Is there a free or cheaper tool that does this? |
| ROI | How does this save time or generate revenue? |
| Frequency | Will we use this daily or weekly? |
| Integration | Does it connect with our existing stack? |
| Contract | Month-to-month or annual? (prefer monthly first) |
| Approval | CEO approval required if >$50/month |
