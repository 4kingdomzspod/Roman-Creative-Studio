## 6. Voice & Tone

### Writing Style
- Lead with outcomes, not features
- Use active voice always
- Short sentences. No fluff.
- Speak to business owners who are busy and results-focused
- Avoid jargon unless speaking to technical audiences

### Example Rewrites
| ❌ Don't Say | ✅ Say Instead |
|-------------|--------------|
| "We build websites" | "We build digital experiences that grow businesses" |
| "Custom web design" | "Websites built specifically to convert your audience" |
| "SEO services" | "Get found by the right customers at the right time" |
| "We work with all industries" | "Deep expertise. Every industry." |

## 7. Logo System

### Primary Logo
Use for: website header, proposals, presentations, email signatures  
File: `logo-primary.svg` (dark bg) / `logo-primary-white.svg` (light bg)

### Stacked Logo  
Use for: social media posts, square formats, merchandise  
File: `logo-stacked.svg` / `logo-stacked-white.svg`

### Icon Mark
Use for: favicon, app icons, profile photos, watermarks  
File: `logo-icon.svg`

### Monogram
Use for: circular profile photos, social media avatars  
File: `logo-monogram.svg`

### Logo Rules
- ✅ Always maintain clear space equal to the height of the "R" in ROMAN around all edges
- ✅ Use white version on dark backgrounds, dark version on light backgrounds
- ❌ Never stretch, rotate, or distort the logo
- ❌ Never change the colors of the logo
- ❌ Never place the logo on a busy background without a clear field
- ❌ Never recreate the logo in a different font
- ❌ Never use low-resolution versions

## 10. Spacing System

All spacing uses a 4px base grid. Every spacing value is a multiple of 4px.

| Token | Value | Usage |
|-------|-------|-------|
| `--space-1` | 4px | Micro spacing |
| `--space-2` | 8px | Tight spacing (icon gaps) |
| `--space-4` | 16px | Default element spacing |
| `--space-6` | 24px | Component internal spacing |
| `--space-8` | 32px | Card padding |
| `--space-12` | 48px | Section internal spacing |
| `--space-16` | 64px | Small sections |
| `--space-20` | 80px | Standard sections |
| `--space-24` | 96px | Large sections |
| `--space-32` | 128px | Hero sections |

**Rule: Never use a spacing value not in this scale.**

## 12. Icon System

**Library: Heroicons (Outline style)**  
**Fallback: Lucide Icons**

### Rules
- ✅ Always use outline (not solid) for UI icons
- ✅ Consistent stroke-width: `1.5` for all icons
- ✅ Size: 16px (inline), 20px (button), 24px (card), 32px+ (feature)
- ✅ stroke-linecap: `round`, stroke-linejoin: `round`
- ❌ Never mix outline and solid in the same view
- ❌ Never use icons smaller than 14px

## 14. Photography Style Guide

### General Principles
- **Real over stock** — Use actual photos over generic stock whenever possible
- **People-focused** — Real people, authentic expressions
- **Premium quality** — Clean, well-lit, sharp focus
- **Consistent color temperature** — Avoid mixing warm and cool toned photos

### By Industry

#### Healthcare & Dental
- Bright, clean, clinical but warm
- Natural smiles, real patients
- Modern office interiors
- Avoid: cheesy "dentist pointing at teeth" stock photos

#### Churches & Nonprofits
- Community, warmth, belonging
- Natural lighting, genuine worship
- Diverse congregations
- Avoid: overly staged "hands raised" stock

#### Startups & Technology
- Clean, modern workspaces
- Diverse teams collaborating
- Screens showing real products
- Avoid: generic stock handshakes

#### Local & Small Business
- Real storefronts, real owners
- Community connection
- Work in progress
- Avoid: corporate stock photos

### Technical Specs
- Minimum resolution: 1200×800px for web
- Format: WebP (with JPEG fallback)
- Hero images: 1920×1080px minimum
- Avatar/headshots: minimum 400×400px, square crop

## 15. Motion & Animation System

### Principles
- **Purposeful** — Every animation communicates something
- **Subtle** — Never let animation distract from content
- **Consistent** — All animations use the same easing and timing

### Standard Animations

| Animation | Duration | Easing | Usage |
|-----------|----------|--------|-------|
| Fade in | 500ms | ease-out | Page elements on scroll |
| Slide up | 500ms | ease-premium | Cards, content blocks |
| Hover lift | 200ms | ease-out | Cards, buttons |
| Menu open | 300ms | ease-premium | Navigation drawer |
| Accordion | 300ms | ease-out | FAQ expand |

### Rules
- ✅ All entrance animations: `data-animate` class + IntersectionObserver
- ✅ Hover transitions: 150-200ms
- ✅ Always support `prefers-reduced-motion`
- ❌ Never animate more than 3 elements simultaneously
- ❌ No animations longer than 700ms for UI elements

## 16. Accessibility Standards

Roman Creative Studio targets **WCAG AA** compliance across all pages.

### Required Standards
- Minimum contrast ratio: 4.5:1 for body text, 3:1 for large text
- All interactive elements must have visible focus states
- All images must have descriptive alt text
- All forms must have associated labels
- Keyboard navigation must work for all interactive elements
- Skip navigation link present on all pages

### Color Contrast
| Foreground | Background | Ratio | Pass? |
|-----------|------------|-------|-------|
| #121417 | #F8F9FA | 18.4:1 | ✅ AAA |
| #D4AF37 | #121417 | 6.8:1 | ✅ AA |
| #FFFFFF | #121417 | 19.4:1 | ✅ AAA |
| #D4AF37 | #FFFFFF | 3.0:1 | ⚠️ Large text only |

**Note:** Never use gold text on white for body copy — only for large headings and decorative elements.

## 17. SEO Standards

Every page must include:
- Unique `<title>` tag (60 characters max)
- Meta description (155 characters max)
- Open Graph tags (`og:title`, `og:description`, `og:image`)
- Canonical URL
- Semantic HTML heading structure (one H1 per page)
- Schema markup (Organization, LocalBusiness, or relevant type)

## 20. Do's and Don'ts

### DO
✅ Start every project with strategy before design  
✅ Use the design token system for every visual value  
✅ Test all designs at mobile, tablet, and desktop  
✅ Verify contrast ratios before shipping  
✅ Use the logo system files — never recreate them  
✅ Follow the spacing scale exactly  
✅ Write copy that leads with outcomes  

### DON'T
❌ Use hardcoded color values in CSS — always use tokens  
❌ Mix icon styles (outline vs solid)  
❌ Use cheesy stock photography  
❌ Build without a spacing system  
❌ Launch without checking Lighthouse scores  
❌ Use the logo at sizes below 32px wide  
❌ Create off-brand components without updating this document
