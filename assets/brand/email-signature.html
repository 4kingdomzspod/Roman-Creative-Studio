Roman Creative Studio — Brand Kit

How to install:
1. Click inside the signature box, select all (Ctrl+A / Cmd+A), copy (Ctrl+C / Cmd+C).
2. Gmail: Settings → See all settings → General → Signature → New → Paste.
3. Outlook: File → Options → Mail → Signatures → New → Paste.
4. Apple Mail: Preferences → Signatures → + → Paste in the right panel.

Use the Dark version for branded/marketing emails. Use the Light version for everyday business correspondence.
